\section{Overview, Methods and Scope}

\begin{frame}{Program Description}
Polocentro was a 1970s occupation and development program. Key facts:
\begin{itemize}
    \item Created by Decree 75,320/1975 to modernize agriculture in selected Cerrado poles in the Center-West and western Minas Gerais
    \item Later expanded in BCB operational guidelines.
    \item Initial commitment of 12 billion cruzeiros orve three years (1.14\% to 0.5\% of GDP)
    \item Intended to act over roughly \textbf{3.7 million hectares} during 1975--79;
    \item Retrospective sources identify about \textbf{202 municipalities}.
    \item Increasing output in cattle, forestry, soybeans, rice, corn, peanuts, cotton and pineapple specifically mentioned as goals
    \item The main instrument were \textbf{extremely lax borrowing conditions}
    \item "Speculative participation" punished by high real interest rates and instant repayment
\end{itemize}
\end{frame}

\begin{frame}{What's Already Known}
\textbf{FJP (1984):} a nine-volume official evaluation
 \begin{itemize}
    \item Documents implementation, production change, and strong concentration of credit/benefits
    \item Before/after comparisons
 \end{itemize}

\textbf{Mueller (1990), Salim (1986), later geography/political economy:}
 \begin{itemize}
    \item faster commercial farming and soy expansion, rising land concentration, weak employment intensity, and small-producer marginalization.
    \item Descriptively  rich; not causal
 \end{itemize}


\end{frame}

\begin{frame}{Main Outcome Variables}

Initially, I want to identify Polocentro's effect on three outcome classes:
\vspace{1em}

\begin{enumerate}
    \item Stated policy goals of local agricultural GDP and specific cultivars
    \vspace{1em}
    \item Migration to treated units
    \vspace{1em}
    \item Environmental devastation of treated units
\end{enumerate}

\end{frame}


\begin{frame}{Later Work: Effect on Not Treated}
What's Polocentro's effect on \textbf{nontreated units?}
\vspace{1em}

Main Questions:
\begin{itemize}
    \item \textbf{"Those who stay"}: how did Polocentro induced outmigration impact the regions from which migration originated?
    \begin{itemize}
        \item 1970 migration network as an exposure measure
    \end{itemize}
\vspace{1em}
    \item \textbf{Aggregate gains or redistribution?}: Did Polocentro increase overall agricultural output? Or did it just affect the "where"?
    \begin{itemize}
        \item Even if ATT is significant, ATNT could negate the overall effect
        \item I'm not sure how to go about identifying this
    \end{itemize}
    \end{itemize}
    
This is not included in this exploratory sweep

\end{frame}

% Treatment and Control Assignment
% ----------------------------
\begin{frame}{What is a Treated Unit?}
Polocentro specified regions of effect. We overlay regions on IBGE's Áreas Mínimas Comparáveis (AMCs) or municipalities to generate treated units.
\vspace{0.5em}

\textbf{For binary assignment:} Take operational guidance as baseline. Consider treated if any of the following are satisfied:
\begin{itemize}
    \item >10\% of the unit's area is in the treated region
    \item The unit's seat is inside the treated region
\end{itemize}
Analyzing each category by itself could provide robustness

\textbf{Nonbinary alternatives}:
\begin{itemize}
    \item Use area share as treatment intensity    
    \item Construct unit-year intensity index based on credit rollout
    \begin{itemize}
        \item Issue: Data acquisition and treatment 
    \end{itemize}
\end{itemize}
\end{frame}



\begin{frame}{What is a Control Unit?}
\textbf{Naive assignment:} A control unit is a nontreated one
\vspace{1em}

\textbf{Two alternatives:}
\begin{itemize}
    \item Proximity: restrict controls to units in the same state/biome as treated ones
    \item Proximity Plus: restrict controls to treatment-neighborhood units
    \item Let the data speak: run propensity scores on many observable dimensions
\end{itemize}
\vspace{1em}

In this presentation, assignment is naive and PS densities are reported.

For inference work, PS weighting seems best

\end{frame}
